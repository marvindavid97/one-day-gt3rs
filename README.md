# ONE DAY — GT3 RS

Eine mobile Single-Page-Geschenkseite für einen NFC-Tag. Die Seite ist bewusst ohne offizielle Logos, Bilder oder geschützte Markenelemente umgesetzt und nutzt nur eine GT3-RS-inspirierte Motorsport-Ästhetik.

## GitHub Pages

1. Repository auf GitHub anlegen, zum Beispiel `one-day-gt3rs`.
2. `index.html`, `README.md` und `.nojekyll` hochladen.
3. Unter **Settings → Pages** als Quelle **Deploy from a branch**, Branch `main` und Ordner `/ (root)` wählen.
4. Die veröffentlichte URL auf den NFC-Tag schreiben.

Die Seite benötigt keinen Build-Schritt, keine externen Assets und keine Serverlogik.
